# Этап 2: редизайн экрана «Достижения»

Сначала выполни «Общий порядок работы над любым этапом» из CLAUDE.md (раздел «🗺 Дорожная карта»), шаги 1–3. Если этап 2 уже ✅ — остановись. От этапа 1 этот этап технически не зависит.

## Проблема

Сейчас `_render_achievements()` (`bot/handlers/profile.py`) отдаёт **все** ачивки (на 2026-09-26 их 59) одним сообщением. Экран трижды подряд упирался в лимит Telegram 4096 символов (тест `test_render_achievements_stays_under_telegram_limit` в `tests/test_handlers.py`), и каждый раз лечили обрезкой описаний ачивок. Разбиваем экран на два уровня — тогда лимит перестаёт быть проблемой навсегда.

## Решения пользователя (2026-09-26) — не менять без согласования

1. **Оглавление** — то, что открывается по кнопке «🏅 Достижения» (свои) и по кнопке достижений в профиле другого игрока. Текст сообщения — только заголовок в текущем формате: `🏅 <b>{title}</b>  ({count} из {total})`. Построчного списка категорий в тексте **нет** — прогресс живёт на кнопках (иначе дублирование). Строки «Последняя полученная» — **не надо** (пользователь отказался). Если тебе кажется, что под заголовком нужна строка-подсказка («Выбери категорию» и т.п.) — предложи текст и спроси, сам не добавляй.
2. **Кнопки категорий — по одной в ряд, прогресс прямо на кнопке**: `🔥 Серии 5/9` — то есть имя категории из `CATEGORY_ORDER` (`bot/services/achievements.py`, там уже есть эмодзи) + ` {получено}/{всего в категории}`. Порядок — `CATEGORY_ORDER`. Скрытые ачивки в знаменатель входят (как и сейчас в общем «N из 59»). Если хочешь помечать полностью закрытую категорию (например ✅ на кнопке) — это новое оформление, сначала спроси.
3. Под кнопками категорий: для своих достижений — те же кнопки, что сейчас в `achievements_kb()` («« К статистике», «« В меню»); для чужих — как сейчас в `player_achievements_kb()` («« К профилю»).
4. **Экран категории** — по нажатию на кнопку категории, редактирует то же сообщение (`edit_text`). Заголовок: имя категории и её прогресс; ниже — список ачивок **этой категории** в текущем формате (сначала ✅ полученные, потом 🔒; скрытые неполученные — `🔒 ???`; пустая строка между пунктами — всё как сейчас в `_render_achievements`). Кнопка **«« Все категории»** — назад к оглавлению (своему или чужого игрока соответственно).
5. **Вернуть полные описания**, урезанные ради лимита, — **но только там, где они хорошо выглядят в строке** (критерий пользователя). См. раздел ниже.

## Технически

- Разбей `_render_achievements` на две функции: рендер оглавления и рендер категории. Посчитать прогресс по категориям — одна вспомогательная функция, общая для текста и кнопок.
- Колбэки. Оглавление оставь на существующих `my_achievements` и `player_achievements_{player_id}` — на них уже ведут кнопки из других экранов. Новые: `ach_cat_{i}` (своя категория, `i` — индекс в `CATEGORY_ORDER`) и `pach_{player_id}_{i}` (категория чужого игрока). **Не начинай новый префикс с `player_achievements_`** — существующий хендлер ловит его через `startswith` и перехватит чужой колбэк. Некорректный/устаревший индекс — `callback.answer(..., show_alert=True)`, без падения (тексты алертов — как у соседних хендлеров, например «Некорректные данные.»).
- Клавиатуры — в `bot/keyboards/inline.py`, рядом с существующими `achievements_kb`/`player_achievements_kb`.

## Полные описания

Описания урезали в трёх релизах. Найди прежние тексты в истории: `git log -p -S'"<id>"' -- bot/services/achievements.py` (подставь id ачивки).
- v2.129.0 урезал: `throne_denied` («Проиграть босс-файт за трон, оставшись претендентом»), `chance_blown` («Потерять статус претендента, не дойдя до боссфайта»), `absolute_zero` («Выиграть матч, где КАЖДАЯ партия закончилась 11:0»), `takova_zhis` («6 матчей подряд с чередованием побед и поражений»), `night_owl` («Выиграть матч, завершённый ночью (0:00–6:00 МСК)»), `first_crown` («Выиграть свой самый первый босс-файт в карьере»), `fatality` («Победить, не отдав сопернику ни одной партии»), `david_goliath` («Победить игрока с рейтингом выше на 100+ pts»).
- v2.128.0 урезал: `deuce_storm`, `no_rest_win`, `weekend_warrior`. v2.127.0: `highlander`, `no_rest_win`, `chance_blown`, `terminator_slain`, `full_circle_week` — прежние тексты ищи в истории.
- Отдельно: 5 ачивок про поражения (`first_pancake`, `blown_lead`, `valley_of_tears`, `punching_bag`, `personal_prey`) с рождения имеют телеграфные описания («10 подряд», «50 поражений», «10 подряд одному») — тоже из-за лимита. Для них предложи понятные формулировки (например «Проиграть 10 матчей подряд»).

**Покажи пользователю таблицу «id | сейчас | предлагаю» и примени только одобренное.** Не восстанавливай вслепую: текст мог быть осознанно переписан позже по другой причине — сверься с текущим кодом.

## Тесты

- Переписать `test_render_achievements_stays_under_telegram_limit`: худший случай теперь — **каждая категория по отдельности** со всеми ачивками полученными (после восстановления описаний). Проверять все категории, а не только самую большую.
- Оглавление: заголовок с верным «N из M»; кнопки — по одной на категорию, в порядке `CATEGORY_ORDER`, с верным прогрессом; внизу правильные кнопки возврата (свои vs чужие).
- Экран категории: только ачивки этой категории; скрытая неполученная — `🔒 ???`, скрытая полученная — раскрыта; кнопка «« Все категории» ведёт на правильное оглавление.
- Хендлеры: свой экран, чужой экран, некорректный индекс категории (алерт, без исключения), несуществующий игрок.
- Проверь, что другие тесты, завязанные на старый `_render_achievements`, обновлены, а не удалены.
