# Mini App клуба: устройство и включение

Мини-приложение Telegram для экранов «только чтение». Первый релиз (v2.160.0): фундамент и страница «Рейтинг клуба», кнопка видна только администратору. v2.161.0: все экраны «только чтение» и переходы между ними. v2.162.0: свой интерфейс приложения (не копия бота): нижнее меню, главная с подиумом, профиль-табло, ачивки сеткой, «ты против …», фото игроков. Бот работает как раньше, если приложение не включено.

## Устройство

| Часть | Где | Что делает |
|---|---|---|
| Данные таблицы | `bot/services/leaderboard.py` | `compute_leaderboard` — одно определение мест, значков и ▲▼ за неделю для экрана бота и для приложения |
| Строки бота | `bot/webapp/text.py` | Готовые строки экранов бота -> элементы приложения: без HTML и эмодзи, «Название: значение» в две колонки, форма точками, полоска прогресса шкалой |
| Подписи и JSON | `bot/webapp/api.py` | Строки приложения («Чемпион · Тим лид», «+1 место», «До #1 Боб: 13.2 очка.») собираются на сервере и покрыты тестами |
| Вход | `bot/webapp/auth.py` | Проверка подписи `initData` (aiogram, HMAC по токену бота), срок жизни 24 часа, игрок ищется по `telegram_id` |
| Веб-сервер | `bot/webapp/server.py` | aiohttp в процессе бота, слушает `127.0.0.1:8081`, только чтение БД |
| Флаги | `bot/webapp/config.py` | Всё из `.env`, без релиза |
| Страница | `webapp/static/` | HTML/CSS/JS без сборки, темы по `colorScheme` Telegram |
| Шрифт | `webapp/static/fonts/` | Raleway (OFL), латиница + кириллица; цифры из системного шрифта, потому что в Raleway нет табличных цифр |

Писать в БД продолжает только бот: второй писатель снова упёрся бы в блокировку SQLite (см. v2.157.2).

## Экраны

| Адрес | Экран |
|---|---|
| `#/` (вкладка «Клуб») | Главная: подиум, «Ты», матч дня, свежие рекорды, матчи дня, разделы клуба |
| `#/rating` (вкладка «Рейтинг») | Таблица рейтинга |
| `#/player/{id}` (вкладка «Я» для своего) | Профиль-табло, раздел «Обзор» |
| `#/player/{id}/matches`, `/achievements`, `/style` | Разделы профиля: матчи, ачивки сеткой, стиль (радар + активность) |
| `#/h2h/{id}` | «Ты против …»: счёт, шанс победы, «что если», стиль обоих, встречи |
| `#/records`, `#/matches`, `#/activity/club`, `#/throne` | Рекорды клуба, все матчи, активность клуба, зал славы |

«Назад» — кнопка Telegram (история переходов браузера). Фото игроков бот берёт из Telegram (`/api/photo/{id}`); у кого фото скрыто настройками приватности — буква на цветном круге.

## Переменные `.env`

| Переменная | Значение | По умолчанию |
|---|---|---|
| `WEBAPP_URL` | Внешний HTTPS-адрес, например `https://<имя>/`. Пусто — приложение выключено: сервер не стартует, кнопки нет | пусто |
| `WEBAPP_AUDIENCE` | `admin` — только `ADMIN_ID`, `all` — все игроки | `admin` |
| `WEBAPP_HOST`, `WEBAPP_PORT` | Где слушает сервер внутри VPS | `127.0.0.1`, `8081` |

Имя хоста в репозиторий не записывается: оно только в `.env` на VPS.

## Включение на VPS (один раз)

Нужен root на VPS. Имя берётся бесплатное: `<IP через дефисы>.sslip.io`, например для `1.2.3.4` это `1-2-3-4.sslip.io`. Сервис sslip.io сам отвечает этим IP, DNS настраивать не нужно.

1. Открыть порты 80 и 443 (если включён `ufw`):
   ```bash
   ufw allow 80,443/tcp
   ```
2. Установить Caddy (пакет есть в Ubuntu 24.04):
   ```bash
   apt update && apt install -y caddy
   ```
3. Записать `/etc/caddy/Caddyfile` (подставить своё имя):
   ```
   1-2-3-4.sslip.io {
       reverse_proxy 127.0.0.1:8081
   }
   ```
   и перезапустить: `systemctl reload caddy`. Сертификат Let's Encrypt Caddy получит сам при первом обращении.
4. Добавить в `/opt/bottennis/.env`:
   ```
   WEBAPP_URL=https://1-2-3-4.sslip.io/
   WEBAPP_AUDIENCE=admin
   ```
   и перезапустить бота: `systemctl restart bottennis`.
5. Проверить: `curl -sI https://1-2-3-4.sslip.io/` отвечает `200`, в логе бота есть «Mini App: веб-сервер слушает 127.0.0.1:8081». В боте у администратора под «Рейтингом клуба» появляется кнопка «Открыть приложение».

## Вход по IP без имени (v2.200.1)

С именем `*.sslip.io` телефон перед каждым запуском ищет адрес у серверов sslip.io за границей; на Wi-Fi владельца это заняло 18,8 с из 20 (замер в журнале запуска, v2.194.0). Let's Encrypt с 15.01.2026 выдаёт сертификаты прямо на IP — тогда искать нечего. Сертификат на IP живёт 6 дней, Caddy продлевает его сам; срок проверяет скилл `prod-check`.

1. Caddy не ниже 2.10 (в Ubuntu 24.04 — 2.6.2, профили ACME он не знает). Официальный репозиторий Caddy:
   ```bash
   cp /etc/caddy/Caddyfile /root/Caddyfile.bak
   apt install -y debian-keyring debian-archive-keyring apt-transport-https curl
   curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/gpg.key' | gpg --dearmor -o /usr/share/keyrings/caddy-stable-archive-keyring.gpg
   curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/debian.deb.txt' | tee /etc/apt/sources.list.d/caddy-stable.list
   apt update && apt install caddy
   ```
   На вопрос о файле настроек — оставить свой (N).
2. В `/etc/caddy/Caddyfile` рядом с блоком sslip.io (его не убирать: кнопки в старых сообщениях чата ведут туда) — блок по IP:
   ```
   1.2.3.4 {
       tls {
           issuer acme {
               profile shortlived
           }
       }
       reverse_proxy 127.0.0.1:8081
   }
   ```
   `caddy validate --config /etc/caddy/Caddyfile --adapter caddyfile`, затем `systemctl reload caddy`; в `journalctl -u caddy` — «certificate obtained successfully».
3. В `/opt/bottennis/.env`: `WEBAPP_URL=https://1.2.3.4/`, затем `systemctl restart bottennis` (кнопка меню «Клуб» обновится при старте).
4. Откат: вернуть в `.env` адрес sslip.io и перезапустить бота; Caddy — `cp /root/Caddyfile.bak /etc/caddy/Caddyfile && systemctl reload caddy`.

Для Telegram новый адрес — новый сайт: память браузера (снимок главной, выбор «во весь экран» на компьютере) начинается заново; память Telegram (цели, подсказки) остаётся.

## Если приложение «вешается» на загрузке

Шкала встаёт на первых процентах, помогает только перезапуск. Две причины, обе учтены:
1. Скрипт Telegram с `telegram.org` — загрузчик в `index.html` с таймаутом и повторами (v2.164.2).
2. HTTP/3: Caddy по умолчанию рекламирует `Alt-Svc: h3=":443"`, а UDP на мобильных сетях часто режется, и клиент ждёт таймаута, прежде чем вернуться на TCP. Приложению HTTP/3 не нужен, его отключают в `/etc/caddy/Caddyfile` глобальным блоком в самом начале файла:
   ```
   {
       servers {
           protocols h1 h2
       }
   }
   ```
   затем `systemctl reload caddy`. Проверка: `curl -sI https://<имя>/ | grep -i alt-svc` ничего не выводит.

## Счётчик экранов

После каждого показанного экрана страница шлёт `POST /api/track {"screen": "…"}` — в `usage_events` пишется `app_<экран>` (`app_home`, `app_rating`, `app_me`, `app_me_matches`, `app_player`, `app_h2h`, …), видно в `/usage` и `scripts/export_usage.py`. Первый экран после запуска добавляет время загрузки — оно в логе сервиса («Mini App: загрузка N мс до первого экрана»), не в базе.

## Итоги и лента (v2.168.0)

Каждая сводка сохраняет клубную часть в `digest_snapshots`; экран `#/summary/<day|week|month|quarter|year>` показывает последнюю. Игрок с приложением получает в чат начало сводки и кнопку на этот экран (`bot/services/digest_delivery.py`). Лента на главной — матчи, ачивки, рекорды и трон за 7 дней. Экран матча — `#/match/<id>`.

## Реакции и память устройства (v2.169.0)

Реакции на матчи — `POST /api/match/<id>/react` с `{"kind": "fire" | "like" | "lol"}`, таблица `match_reactions`, бот о них не пишет. Подсказка первого запуска (`hint_home_v1`) и список увиденных ачивок (`seen_achievements_v1`) хранятся в CloudStorage Telegram, без него — в localStorage. Свёрнутое дольше минуты приложение при возврате обновляет текущий экран на месте.

## «Когда играют», «Использование», итоги года (v2.170.0)

`#/when` и `#/when/me` — матчи за 90 дней по дням недели и часам МСК. `#/usage` — отчёт счётчика за 30 дней, только `ADMIN_ID` (остальным 404). Вкладка «Год» в «Итогах» дополнена личным годом и, после 30.12 12:00, неформальными званиями; голосование — только в боте.

## Главная и лента (v2.171.0)

Порядок главной: подиум, «Ты», меню клуба плиткой, матч дня, лента. Лента — 30 дней, первые 15 событий в `/api/home` (`feed`, `feed_more`), дальше `GET /api/feed?offset=N`. Реакции: `fire`, `like`, `lol`, `poo`.

## Первый запуск и мгновенный старт (v2.180.0)

Шрифт Raleway урезан `scripts/subset_font.py` (исходник — `webapp/fonts-src/`); при смене `unicode-range` в app.css — перезапустить скрипт. app.js и шрифт предзагружаются из `<head>`. Главная хранится на устройстве (`localStorage`, ключ `snap_home_v1`, привязка к игроку) и показывается сразу при следующем запуске. Бюджет загрузки держит `tests/e2e/test_boot_budget_e2e.py`: первый запуск ≤ 150 КБ статики, повторный ≤ 8 КБ, главная на «быстром 3G» ≤ 3 с — превышение валит CI.

## Скорость (v2.172.0)

app.js, app.css и icons.svg отдаёт `bot/webapp/assets.py`: из памяти, сжатыми gzip, по адресу с версией `?v=<хеш>` — навсегда в кэше браузера. index.html всегда свежий (`no-store`) и ссылается на текущие версии. Ответы API от 1 КБ сжимаются. Caddy настраивать не нужно: он передаёт сжатый ответ как есть.

## Запуск и заставка Telegram (v2.178.0)

Telegram держит свою заставку с полоской, пока страница не сообщит «готово» (`web_app_ready`) или не загрузится целиком. Поэтому: скрипт `telegram-web-app.js` — своя копия в `webapp/static/` (не с telegram.org; обновлять `scripts/update_telegram_js.py`), загрузчик в `index.html` сообщает «готово» сразу, до app.js, а если скрипт не загрузился — напрямую через мост Telegram. Нельзя добавлять в страницу ресурсы с чужих доменов, которые грузятся до `load`, и нельзя откладывать «готово» до ответа сети. Проверка — `tests/e2e/test_boot_splash_e2e.py` (настоящая `index.html`, висящий telegram.org).

## Два режима бота

Без `WEBAPP_URL` бот полный. С ним — короткий для тех, кому приложение доступно: «Мой рейтинг» (короткая карточка), рейтинг с переходом в профили приложения, «📱 Подробнее в приложении» вместо разделов клуба, после матча «📱 Рейтинг в приложении» с анимацией подъёма. Ссылка на экран: `webapp_link(telegram_id, "player/5")` → `?r=player/5`; страница открывает маршрут из `r`, `from` — место до матча.

## Входы из бота

| Где | Подпись | Кому |
|---|---|---|
| Строка в главном меню бота, сразу под «Вызвать на матч» | «Открыть приложение» | тем, кому разрешено (`WEBAPP_AUDIENCE`) |
| Кнопка меню Telegram слева от строки ввода | «Клуб» | чату администратора (`admin`) или всем (`all`) |
| Под таблицей «Рейтинг клуба» | «Открыть приложение» | тем же |

Кнопка меню выставляется при каждом старте бота (`bot/webapp/menu_button.py`): после смены `.env` достаточно перезапустить сервис.

## Выключение и откат

- Скрыть от всех, кроме администратора: `WEBAPP_AUDIENCE=admin`, перезапуск.
- Выключить совсем: удалить `WEBAPP_URL` из `.env`, перезапуск. Кнопки в меню и «Клуб» слева от строки ввода пропадают (кнопка меню возвращается к списку команд), сервер не стартует, бот работает как раньше.

## Превью перед релизом

`scripts/preview_miniapp.py` поднимает веб-часть на временной базе с придуманными данными и заглушкой Telegram (прод и рабочая база не трогаются): `http://127.0.0.1:8770/preview`, тёмная тема — `?dark=1`. Порядок проверки экранов — скилл `miniapp-preview` (`.claude/skills/miniapp-preview/SKILL.md`).

## Проверка на устройствах

Перед `WEBAPP_AUDIENCE=all`: открыть на iOS, Android и Telegram Desktop в светлой и тёмной теме; проверить, что своя строка выделена, цифры рейтинга стоят ровной колонкой, страница не открывается вне Telegram («Откройте приложение из бота.»).
