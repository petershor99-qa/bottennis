# Mini App клуба: устройство и включение

Мини-приложение Telegram для экранов «только чтение». Первый релиз (v2.160.0): фундамент и страница «Рейтинг клуба», кнопка видна только администратору. Бот работает как раньше, если приложение не включено.

## Устройство

| Часть | Где | Что делает |
|---|---|---|
| Данные таблицы | `bot/services/leaderboard.py` | `compute_leaderboard` — одно определение мест, значков и ▲▼ за неделю для экрана бота и для приложения |
| Подписи и JSON | `bot/webapp/api.py` | Строки приложения («Чемпион · Тим лид», «+1 место», «До #1 Боб: 13.2 очка.») собираются на сервере и покрыты тестами |
| Вход | `bot/webapp/auth.py` | Проверка подписи `initData` (aiogram, HMAC по токену бота), срок жизни 24 часа, игрок ищется по `telegram_id` |
| Веб-сервер | `bot/webapp/server.py` | aiohttp в процессе бота, слушает `127.0.0.1:8081`, только чтение БД |
| Флаги | `bot/webapp/config.py` | Всё из `.env`, без релиза |
| Страница | `webapp/static/` | HTML/CSS/JS без сборки, темы по `colorScheme` Telegram |
| Шрифт | `webapp/static/fonts/` | Raleway (OFL), латиница + кириллица; цифры из системного шрифта, потому что в Raleway нет табличных цифр |

Писать в БД продолжает только бот: второй писатель снова упёрся бы в блокировку SQLite (см. v2.157.2).

## Переменные `.env`

| Переменная | Значение | По умолчанию |
|---|---|---|
| `WEBAPP_URL` | Внешний HTTPS-адрес, например `https://<имя>/`. Пусто — приложение выключено: сервер не стартует, кнопки нет | пусто |
| `WEBAPP_AUDIENCE` | `admin` — только `ADMIN_ID`, `all` — все игроки | `admin` |
| `WEBAPP_HOST`, `WEBAPP_PORT` | Где слушает сервер внутри VPS | `127.0.0.1`, `8081` |

Имя хоста в репозиторий не записывается: оно только в `.env` на VPS.

## Включение на VPS (один раз)

Нужен root на VPS. Имя берётся бесплатное: `<IP через дефисы>.sslip.io`, например для `1.2.3.4` это `1-2-3-4.sslip.io`. Сервис sslip.io сам отвечает этим IP, DNS настраивать не нужно.

1. Открыть порты 80 и 443 (если включён `ufw`):
   ```bash
   ufw allow 80,443/tcp
   ```
2. Установить Caddy (пакет есть в Ubuntu 24.04):
   ```bash
   apt update && apt install -y caddy
   ```
3. Записать `/etc/caddy/Caddyfile` (подставить своё имя):
   ```
   1-2-3-4.sslip.io {
       reverse_proxy 127.0.0.1:8081
   }
   ```
   и перезапустить: `systemctl reload caddy`. Сертификат Let's Encrypt Caddy получит сам при первом обращении.
4. Добавить в `/opt/bottennis/.env`:
   ```
   WEBAPP_URL=https://1-2-3-4.sslip.io/
   WEBAPP_AUDIENCE=admin
   ```
   и перезапустить бота: `systemctl restart bottennis`.
5. Проверить: `curl -sI https://1-2-3-4.sslip.io/` отвечает `200`, в логе бота есть «Mini App: веб-сервер слушает 127.0.0.1:8081». В боте у администратора под «Рейтингом клуба» появляется кнопка «Открыть приложение».

## Выключение и откат

- Скрыть от всех, кроме администратора: `WEBAPP_AUDIENCE=admin`, перезапуск.
- Выключить совсем: удалить `WEBAPP_URL` из `.env`, перезапуск. Кнопка пропадает, сервер не стартует, бот работает как раньше.

## Проверка на устройствах

Перед `WEBAPP_AUDIENCE=all`: открыть на iOS, Android и Telegram Desktop в светлой и тёмной теме; проверить, что своя строка выделена, цифры рейтинга стоят ровной колонкой, страница не открывается вне Telegram («Откройте приложение из бота.»).
